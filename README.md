# MaxeyQuery

iOS process enumeration research project.

## Build

GitHub Actions builds an unsigned iOS device IPA.

1. Push this repository to GitHub.
2. Open Actions.
3. Select Build MaxeyQuery IPA.
4. Download MaxeyQuery-unsigned-IPA.

## Important

The IPA is unsigned and cannot be installed directly.

Process visibility depends on iOS permissions and sandbox restrictions.
This project does not include a sandbox escape.
